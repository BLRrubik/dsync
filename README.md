# dsync

Утилита для одностороннней синхронизации директорий: приводит содержимое целевой директории (`dest`) в соответствие с исходной (`source`).

## Возможности

- Рекурсивный обход обеих директорий и построение таблицы `путь → SHA-256 хэш` для каждого файла.
- Хэширование файлов параллельно (пул из 10 воркеров) для ускорения на больших деревьях.
- Сравнение состояний источника и назначения:
  - **Копирование** — файлы, которые есть в источнике, но отсутствуют в назначении.
  - **Обновление** — файлы, которые есть в обеих директориях, но их содержимое отличается (хэш не совпадает).
  - **Удаление** — файлы, которые есть в назначении, но отсутствуют в источнике.
- Реальное выполнение операций: копирование (с созданием недостающих поддиректорий), перезапись при обновлении, удаление лишних файлов.
- Прогресс-бар (`github.com/schollz/progressbar/v3`) с общим числом операций (`toCopy + toUpdate + toDelete`), обновляется после каждой операции.
- Цветной вывод (`github.com/fatih/color`) по типу операции:
  - 🟢 зелёный — `[КОПИРОВАНИЕ]`
  - 🟡 жёлтый — `[ОБНОВЛЕНИЕ]`
  - 🔴 красный — `[УДАЛЕНИЕ]`

## Требования

- Go 1.26+

## Сборка

Бинарник собирается в директорию `bin/`:

```bash
go build -o bin/dsync .
```

## Запуск

Собранный бинарник:

```bash
./bin/dsync <source> <dest>
```

Либо без сборки, напрямую через `go run`:

```bash
go run main.go <source> <dest>
```

где:
- `<source>` — путь к исходной директории (эталон);
- `<dest>` — путь к целевой директории, которая будет приведена в соответствие с `<source>`.

## Пример работы

```
$ ./bin/dsync ./source ./dest
Синхронизация...
100% |███████████████████████████████████████| (3/3)

[КОПИРОВАНИЕ] a.txt
[ОБНОВЛЕНИЕ] b.txt
[УДАЛЕНИЕ] c.txt

Синхронизация завершена!
```
